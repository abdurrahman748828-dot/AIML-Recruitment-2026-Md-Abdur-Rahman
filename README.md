### Task 1 — Air Quality Forecasting

The objective of this task is to analyse historical air-quality measurements and build a machine-learning model to predict future air quality.

The prediction problem is formulated as:

> Predict the next-hour `CO(GT)` concentration using historical air-quality, sensor, environmental and time-related features.

## 2. Problem Statement

Air-quality measurements vary over time due to changes in pollutants, environmental conditions and daily patterns.

The goal of this project is to use historical air-quality data to predict the **CO concentration for the next hour**.

The project uses the UCI Air Quality dataset, which contains hourly measurements of different pollutants, sensor responses and environmental variables such as temperature and humidity.
